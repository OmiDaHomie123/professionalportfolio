# Omkar Siddeswaran — Portfolio

Static one-page portfolio. No build step.

## Files
- `index.html` — the site (open this; GitHub Pages serves it automatically)
- `support.js` — runtime the page needs (keep next to index.html)
- `styles.css` — design tokens and components
- `assets/` — photos and logo

## Adding the Harris video
Drop an MP4 named `harris-video.mp4` into `assets/`. The placeholder is replaced automatically.

## Publish on GitHub Pages
1. Upload everything in this folder to the repo root.
2. Repo → Settings → Pages → Source: `main` branch, `/ (root)`.
